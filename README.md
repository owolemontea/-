# 匕首之心角色卡（Owlbear Rodeo 插件）

一个为枭熊（Owlbear Rodeo）做的「匕首之心 / Daggerheart」角色卡插件：

- 📇 **JSON 导入车卡**：支持「匕首之心角色卡工具」导出的 JSON（粘贴或选文件）
- 🔗 **绑定棋子**：右键棋子即可绑定车卡
- 👆 **点棋子弹角色卡**：选中绑定的棋子，自动弹出角色卡
- 🎲 **点数据投骰**：点属性 / 武器命中 / 武器伤害，弹出投骰窗（默认骰子已填好，可随意调整）
- ✨ **全场骰子特效**：投骰时所有玩家屏幕播放动画——骰子飞入 + 老虎机滚动 + 结果大字（点击穿透不挡操作）
- ⌨️ **表达式投骰**：直接输入 `2d12+3` 回车即可，中文标点自动识别，示例按钮一键填入
- ⚖️ **双色骰**：核心判定 2d12，第一颗 = 希望骰（蓝），第二颗 = 恐惧骰（红）
- ➕➖ **优劣势**：优势 = 结果 +1d6，劣势 = 结果 −1d6
- 🌑 **暗骰**：主持人可投只有自己看得到结果的暗骰
- 📜 **投骰历史**：自动记录最近 30 次，点击即可重新填入
- 💚 **实时数值**：生命 / 压力 / 希望 / 护甲槽 / 金币 可随时调整，全房间同步

**不需要安装任何开发工具**（没有 Node.js 也能用、也能改）。

## 一、部署（把插件放到网上）

枭熊只能加载 **https 网址** 上的插件，所以需要把整个文件夹放到一个静态托管空间。
推荐 **GitHub Pages**（免费）：

1. 注册 GitHub，新建一个仓库（名字随意，比如 `daggerheart-obr`）
2. 把本文件夹里所有文件上传到仓库根目录（网页端直接拖拽上传即可）
3. 仓库 → Settings → Pages → Source 选 `main` 分支 + `/ (root)` → Save
4. 等 1 分钟，得到网址：`https://你的用户名.github.io/仓库名/`
5. 插件地址 = 这个网址 + `manifest.json`，即：
   `https://你的用户名.github.io/仓库名/manifest.json`

> 其他选择：Cloudflare Pages、Netlify、Vercel、自己的服务器，同理。
> 只要 `manifest.json` 能被 https 访问到即可。

## 二、安装到枭熊

1. 打开枭熊房间
2. 左下角 **Extras（扩展）→ Extensions → Add**
3. 粘贴你的插件地址（上面的 manifest.json 链接）→ 确认
4. 在扩展列表里打开开关

安装后左上角会出现小匕首图标。

## 三、使用

1. **导入车卡**：点小匕首图标 → 粘贴 JSON 或「选择文件」（.json / .txt 都行）→ 导入
2. **绑定棋子**：
   - 方式 A：场景里选中棋子 → 在面板里点该卡旁的「绑定到选中棋子」
   - 方式 B：场景里 **右键棋子 → 匕首之心：绑定车卡** → 选卡
3. **看卡**：点选已绑定的棋子，角色卡自动弹出
4. **投骰**：
   - 点属性（如力量）→ 弹出 `2d12+3`
   - 点武器「命中」→ `2d12+属性值`；点「伤害」→ `熟练值d伤害骰+加值`
   - 弹窗里可直接改表达式（回车生效）、用示例按钮、调骰子数量/面数/加值、切优势(+1d6)/劣势(−1d6)
   - 主持人可见「暗骰」选项：只有自己能看到结果
   - 点「投掷」→ 全场播放骰子动画（飞入+老虎机滚动），结果浮现在棋子头顶 8 秒
     （2d12 时蓝=希望骰，红=恐惧骰）
   - 历史记录自动保存最近 30 次，点击可重新填入
5. **调数值**：角色卡上直接点生命/压力/护甲/金币方格、希望值 +/−，全房间同步

## 四、规则说明（已内置）

| 项目 | 规则 |
|---|---|
| 熟练值 | 1级=1，2-4级=2，5-7级=3，8-10级=4 |
| 核心判定 | 2d12（希望骰+恐惧骰）+ 属性值 |
| 武器命中 | 2d12 + 武器对应属性值 |
| 武器伤害 | 熟练值颗武器伤害骰 + 武器自带加值（如 3d10+6） |
| 优势 / 劣势 | 总结果 +1d6 / −1d6 |

车卡 JSON 里的头像图片（base64）在导入时会被丢弃，不影响其他数据。

## 五、常见修改

- **改熟练值表**：`js/carddata.js` 里的 `proficiencyForLevel`
- **改优势骰**（比如换成 d8）：`js/dice-engine.js` 里的 `applyMode`
- **改界面文字/样式**：对应 `js/ui-*.js` 和 `css/common.css`
- **改插件名字/图标**：`manifest.json` 和 `icon.svg`

改完后重新上传到托管空间即可（刷新房间生效）。

## 六、自测

插件部署后，浏览器打开 `https://你的地址/test.html`，点「运行全部测试」，
可验证骰子表达式解析（含中文标点）、熟练值表、车卡解析、默认骰子是否正确。

## 七、骰子系统说明（参考 obr-suite 设计）

骰子系统借鉴了 obr-suite 的架构思路（开源 GPL-3.0 项目，作者 FullPeople）：

- **特效动画**：投骰结果通过广播发给房间内所有客户端，每个客户端自己播放
  全屏"飞入 + 老虎机滚动"动画（点击穿透，不影响操作），动画约 4.7 秒后自动关闭
- **表达式引擎**：自研精简版，支持 `XdY±Z` 组合与中文标点自动识别
- 匕首之心的优势/劣势按规则实现为 ±1d6（而非 D&D 的"多投取高"）
- 高级功能（音效、骰子皮肤、回放、固定结果、多目标）暂未移植，如需要可再加
